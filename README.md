# KingdomsSpire · 三国尖塔

> 一款基于 Cocos Creator 3.8.8 开发的三国题材 Roguelike 卡牌构筑游戏，核心灵感来源于《杀戮尖塔》，融入独特的**「虚影降临」**战斗机制与三国武将主题。

---

## 🎮 游戏简介

在《三国尖塔》中，你将选择一位英雄，攀登层层险境，通过构筑卡组、收集遗物、驾驭三国名将的**虚影之力**，挑战魏吴两大阵营的强敌。

**核心特色：虚影降临系统** —— 打出「降临」牌可在战场上召唤三国武将的虚影（关羽·武圣 / 诸葛亮·卧龙 / 赵云·无双），每位虚影提供独特的常驻战斗加成，离场时触发强力效果。在三者之间灵活切换，打出组合技，是制胜的关键。

---

## 🎯 核心玩法

| 系统 | 说明 |
|------|------|
| 🧙 **角色选择** | 3 位可选角色，各有不同的起始属性与遗物 |
| 🗺️ **地图探索** | 7 列 × 17 层程序化生成的分支地图，自由选择路线 |
| ⚔️ **回合制战斗** | 能量驱动的手牌管理战斗，包含攻击/技能/能力/状态四种卡牌类型 |
| 👻 **虚影降临** | 核心机制 —— 召唤武圣/卧龙/无双三位虚影，获取常驻增益与离场爆发 |
| 💎 **遗物收集** | 5 种遗物提供被动效果，影响战斗与资源获取 |
| 🎪 **随机事件** | 8 个随机事件，提供分支选择与风险/回报决策 |
| 🛒 **商店系统** | 购买卡牌、遗物、药水，或移除不需要的卡牌 |
| 🔥 **营火休息** | 回复生命或锻造升级卡牌 |
| 📜 **对局记录** | 自动保存运行历史（最多 20 条），记录胜败与统计数据 |

## 👻 虚影系统详解

虚影是本作最核心的战斗机制。打出**降临牌**后，对应武将的虚影将覆盖到战场上，提供**常驻效果**；当虚影被替换或强制离场时，触发**离场效果**。

### 武圣 · 关羽
| 阶段 | 效果 |
|------|------|
| **降临时** | 对所有敌人造成 12 点伤害 |
| **常驻** | 所有攻击变为群体伤害，且额外 +2 伤害 |
| **离场** | 获得 1 层力量 |

### 卧龙 · 诸葛亮
| 阶段 | 效果 |
|------|------|
| **降临时** | 抽 2 张牌 |
| **常驻** | 每打出一张技能牌，手牌中所有降临牌费用 -1（最低至 0） |
| **离场** | 获得 5 点格挡 |

### 无双 · 赵云
| 阶段 | 效果 |
|------|------|
| **降临时** | 对指定敌人造成 28 点伤害 |
| **常驻** | 格挡牌效果转为攻击且数值 +5 |
| **离场** | 下回合能量上限 +2 |

> 💡 **策略深度**：利用「过河拆桥」强制离场、「血祭」零费召唤、「兵势险要」离场抽牌等卡牌，在三位虚影间构建连携 combo。

## 🃏 卡牌一览

游戏共 **15 张**独特卡牌，分为四种类型：

### 攻击牌（红色）
| 卡牌 | 费用 | 效果 |
|------|------|------|
| 打击 | 1 | 造成 6 点伤害 |
| 打击+ | 1 | 造成 9 点伤害 |
| 重击 | 2 | 造成 8 点伤害 |
| 降临：武圣 | 2 | AOE 12 伤害 + 召唤武圣 |
| 降临：无双 | 2 | 单体 28 伤害 + 召唤无双 |

### 技能牌（蓝色）
| 卡牌 | 费用 | 效果 |
|------|------|------|
| 防御 | 1 | 获得 5 点格挡 |
| 生存者 | 1 | 消耗：获得 8 点格挡 |
| 降临 | 1 | 覆盖基础虚影，获得 4 格挡 |
| 降临：卧龙 | 0 | 抽 2 张牌 + 召唤卧龙 |
| 锦囊 | 0 | 抽 1 张牌，有虚影时抽 2 张（消耗） |
| 过河拆桥 | 1 | 强制虚影离场 + 8 格挡 |
| 血祭 | 0 | 失去 3 生命，随机降临牌 0 费加入手牌（消耗） |

### 能力牌（紫色）
| 卡牌 | 费用 | 效果 |
|------|------|------|
| 兵势险要 | 2 | 虚影离场时可弃 1 牌换 1 能量 + 抽 1 牌（消耗） |

### 状态牌（灰色 · 负面）
| 卡牌 | 效果 |
|------|------|
| 灼伤 | 无法打出，回合结束时在手牌中失去 2 生命 |
| 灼伤+ | 无法打出，回合结束时在手牌中失去 4 生命 |
| 铁索 | 进入手牌时本回合无法打出降临牌，回合结束时消耗 |

## 👹 敌人与 Boss

敌人分为两大阵营，各有独特的战斗风格：

### 第一层 · 魏国（重甲 / 力量成长）

| **乱世奸雄·曹操** | Boss | 240 | 召唤虎豹骑 + 无虚影时回血，检验 AOE 能力 |

### 第二层 · 吴国（连击 / 灼烧）
| 敌人 | 类型 | 生命 | 特色 |
|------|------|------|------|
| **锦帆贼·甘宁** | 精英 | 130 | 偷牌 + 抽牌叠甲，检验手牌运转效率 |
| **大都督·周瑜** | Boss | 320 | 塞灼伤/铁索污染牌库，检验爆发斩杀能力 |

## 🗺️ 地图探索

- **程序化生成**：7 列 × 17 层分支地图，6 条独立路径同时生长
- **节点类型**：起始 → 怪物 / 精英 / 商店 / 营火 / 事件 → Boss
- **平衡机制**：防止连续战斗 ≥4 场、强制商店出现、最顶层固定为营火
- **交互操作**：支持缩放、平移、触控捏合手势
- **路径追踪**：粉色高亮标记已走过的路线

## 🚀 快速开始

1. 使用 **Cocos Creator 3.8.8** 打开项目根目录
2. 从编辑器运行入口场景：`assets/scenes/MainMenu.scene`
3. 完整流程场景链：
   ```
   MainMenu → CharSelect → InitialReward → GameMap → Battle / Event / Shop / Rest → …
   ```
