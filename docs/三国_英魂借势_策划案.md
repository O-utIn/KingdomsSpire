#### 《杀戮尖塔2》Mod策划案：三国·英魂借势

#### 核心定位
- **Mod类型**：新角色 + 核心机制扩充。这是一个以“高风险高回报”为特点的召唤流角色Mod。
- **视觉与主题**：
    - **风格**：暗黑厚涂奇幻风。严格遵循《杀戮尖塔》的美学标准，采用低饱和度、高对比度的厚涂风格。将三国元素进行“尖塔化”处理——强调沉重感、扭曲感和写实感。背景是阴暗潮湿的古战场、布满铁锈的刑具和扭曲的枯木。
    - **立绘**：角色“祭酒”是一个被诅咒缠身的凡人。他身披残破且沾满干涸血迹的汉代皮甲，皮肤呈现出病态的苍白，双眼被粗糙的麻布条缠绕（致敬尖塔角色的眼部特征），手中提着一盏燃烧着幽绿灵魂火焰的青铜提灯。
    - **特效**：攻击特效不是飘逸的剑气，而是沉重的金属撞击火花与暗红色的能量撕裂；召唤名将时，并非祥云缭绕，而是伴随着类似“腐化”或“虚空”的黑色粒子与血红闪电，仿佛英灵是从地狱裂缝中被强行拽出的。

#### 角色逻辑规划
- **角色名**：祭酒
- **初始卡组** (10张)：
    - 打击 x 4
    - 防御 x 3
    - 《招魂术》 x 2 (技能：获得2点能量。消耗。若场上有【虚影】，改为获得3点能量。)
    - 《请神》 x 1 (技能：从抽牌堆检索一张【降临】牌加入手牌。)
- **角色机制**：【虚影】
    - **核心关键词**：【降临】—— 打出时立即触发强力效果，并赋予玩家一层【虚影】状态。
    - **运作规则**：
        - **唯一性**：玩家场上只能存在一个【虚影】。
        - **瞬时性**：在玩家回合结束阶段，【虚影】会触发“离场效果”后消失。
        - **强制替换**：若打出新的【降临】牌，旧的【虚影】会立即触发“离场效果”并消失，随后被新的覆盖。
- **成长性**：
    - **1层**：依赖基础【降临】牌的高数值进行爆发，利用凡人牌检索。
    - **2层**：通过遗物（如《英魂灵龛》）强化【虚影】离场后的收益，形成“召唤-离场-增益”的循环。
    - **3层**：利用Boss遗物或高阶卡牌（如《天命之印》）实现【虚影】常驻，转型为“神将降临”的压制流。

#### 遗物逻辑
- **初始遗物**：【英魂灵龛】
    - **获取途径**：初始自带。
    - **触发时机**：回合结束阶段（在【虚影】消失判定之后）。
    - **数值收益**：
        - 若离场的是**攻击型**虚影：下回合第一张攻击牌伤害 **+50%**。
        - 若离场的是**技能型**虚影：下回合开始时，能量 **+1**。
    - **平衡性**：此遗物鼓励玩家频繁切换虚影，而非死守一张牌，避免了“无限流”的枯燥。
- **Boss遗物**：【天命之印】
    - **获取途径**：Boss宝箱掉落。
    - **触发时机**：打出【降临】牌时。
    - **数值收益**：消耗1层充能（上限3层）。若充能已满，该【虚影】**不会在回合结束时消失**。
    - **平衡性**：对比原版“灵能之锤”，此遗物需要3回合的预热（攒充能）才能获得常驻效果，且失去了每回合结束时的遗物触发收益，符合风险回报比。

#### 战斗行为逻辑
针对新增的敌对阵营（魏、吴、群雄），设计针对性的AI逻辑。

- **精英怪**：许褚 (魏)
    - **意图逻辑**：
        - 第1回合：【格挡】获得15点格挡。
        - 第2回合：【重击】造成18点伤害。若玩家场上有【虚影】，改为造成24点伤害并施加2层虚弱。
        - 第3回合：【嘲讽】强制玩家下回合必须攻击自己。
    - **数值曲线**：血量 120 (L1) / 160 (L2) / 200 (L3)。
    - **弱点设计**：许褚极度依赖玩家场上有【虚影】来触发高伤模式。玩家可通过使用凡人牌（无虚影）来“骗”过许褚的低伤回合，或使用快速爆发的虚影（如赵云）在许褚行动前将其击杀。

- **Boss**：曹操 (魏)
    - **意图逻辑**：
        - 技能A：【奸雄】获得10点格挡。若玩家本回合打出的【降临】牌数量 > 0，曹操获得1层强壮。
        - 技能B：【横槊赋诗】对所有玩家造成12点伤害。
        - 循环：A -> A -> B -> A -> A -> B...
    - **弱点设计**：曹操会随着【降临】牌的使用越来越强。玩家需要控制【降临】的频率，或者利用“回合结束”触发的遗物效果在曹操行动前将其斩杀。

#### 平衡性验证
- **卡组压力测试**：
    - **无限流风险**：通过《招魂术》和《祭坛》的配合，理论上可以实现每回合抽牌。
    - **反制措施**：引入状态牌**《心魔》**（在抽牌堆生成，打出后失去2点能量）来限制过度抽牌。
- **联动性说明**：
    - **Combo示例**：玩家打出【智绝·诸葛亮】（抽3张） -> 触发遗物【英魂灵龛】（下回合能量+1） -> 下回合利用额外能量打出【武圣·关羽】（全场AOE）。
    - **数值封顶**：【虚影】的增益效果（如赵云的回血）设定为每回合上限5点，防止配合多段攻击卡牌导致数值溢出。
- **反制措施**：
    - **怪物机制**：部分精英怪拥有**【驱散】**能力，可以直接移除玩家的【虚影】状态，迫使玩家重新规划手牌资源。
    - **事件**：在地图事件中，有概率遇到“伪神像”，选择祭拜会获得金币，但会在卡组中加入一张无法消耗的《破碎的神格》（诅咒牌，每回合扣血）。
