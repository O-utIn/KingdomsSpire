# 三国尖塔数值1.0



## 初始遗物（能量循环）

初始遗物：**【引魂灯】**
效果： 每回合中，当你**第一次**通过打出**【降临】**牌进行**【虚影】**覆盖时，获得 **1**点能量 并抽**1**张牌。



## 基础牌组 (10张)

打击 (x4)：1费，造成6点伤害。
防御 (x4)：1费，获得5点格挡。
《降临》 (x1)：1费，（核心卡牌）进行【虚影】覆盖，同时获得4点格挡。
《锦囊》 (x1)：0费，技能。抽1张牌。若场上有【虚影】，改为抽2张牌。
